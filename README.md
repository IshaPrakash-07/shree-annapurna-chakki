# Shree Annapurna Flour Mill — Owner & Client Digital Ledger

A frosted-glass, interactive **HTML5, CSS3, JavaScript, and React 18** web application (PWA) built for Indian flour mills (*Chakki*) at **₹5/kg**.

## Features
- **Clean Owner Edition**: Ready for real flour mill owners with zero demo clutter.
- **Frosted-Glass Pastel Orange & Cream UI**: Smooth animations, blurred glassmorphism surfaces, rolling real-grain photo carousel, and Light / Warm Dark mode toggle.
- **Role-Based Portals**: Separate **Owner Portal** and **Client Portal** (clients see only their own orders and remaining balance; owner gets instant alerts when a new client registers).
- **Quick Grinding Cost Estimator**: Interactive ₹5/kg cost calculator on the Grains & Rates tab.
- **Multilingual UI**: Instant **English**, **Hindi**, and **Marathi** switching (including dynamic Chakki title translation).
- **Weekly Grain Revenue & Collection Gauge**: Tracks 7-day revenue and weight across **Gehu, Bajara, Jwari, Laddu Mixture, Bati Flour, and Chana Daal** with real grain photography, plus **Backup** JSON export.
- **Installable Mobile App (PWA)**: Includes `manifest.json` and `sw.js` for Android home-screen installation.

## Run Locally
Serve this folder over any local HTTP server (for example `npx serve .` or `python -m http.server 8080`) and open `http://localhost:8080`.
